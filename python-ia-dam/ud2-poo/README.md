# UD2 · Programación orientada a objetos en Python

Apuntes de la unidad, 4 h (05/10 – 19/10).

- **[UD2-programacion-orientada-a-objetos.md](UD2-programacion-orientada-a-objetos.md)**: los apuntes completos de la unidad.
- **[listados/tienda/](listados/tienda/)**: el paquete de la tienda, el mismo ejemplo que se construye en Java en la UD0 de Acceso a Datos: `modelo.py`, `formatos.py`, `repositorio.py`, `servicio.py` y `app.py`.
- **[listados/](listados/)**: los listados sueltos de los apuntes como ficheros `.py`.
- **[figuras/](figuras/)**: las figuras de los apuntes, en SVG. Las que empiezan por `fig-0-` y `fig-1-` vienen del módulo de Acceso a Datos (CC0) y se usan sin cambios, para que el alumnado reconozca los mismos esquemas en los dos módulos.

Todo se ejecuta desde `listados/`, con el entorno virtual activado:

```bash
cd ud2-poo/listados
python listado_2_04_producto_en_uso.py
python -m tienda.app
```
