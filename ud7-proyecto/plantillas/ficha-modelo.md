# Ficha del modelo · plantilla

Rellena esta tabla en el `README.md` de tu proyecto. Entre 15 y 20 líneas.

| Campo | Qué escribir |
| --- | --- |
| Problema | Qué predices y si es regresión o clasificación |
| Decisión asociada | Qué decisión cambia gracias a esta predicción |
| Datos | Origen, número de filas, periodo, licencia |
| Características | Columnas usadas y, sobre todo, las descartadas y por qué |
| Modelo | Algoritmo, hiperparámetros elegidos y cómo se eligieron |
| Partición | Tamaños, semilla y estrategia de validación |
| Métricas | Las del conjunto de prueba, en las unidades del objetivo |
| Referencia ingenua | Qué resultado da predecir la media o la clase mayoritaria |
| Dónde falla | Métricas por grupos: en qué categorías el error es mayor |
| Sesgo | Si sobreestima o infraestima en algún grupo |
| Límites de uso | Rangos fuera de los datos, usos para los que NO sirve |
| Versión | Versión de las bibliotecas y fecha de entrenamiento |
